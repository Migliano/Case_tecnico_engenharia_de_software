# Case_tecnico_engenharia_de_software
Aplicação full stack de cadastro de pessoas com validação de dados, consulta automática de endereço via CEP, persistência em banco de dados e geração automática de login único com 7 caracteres baseado no nome do usuário. Desenvolvida com front-end e back-end separados, seguindo regras de negócio e boas práticas de arquitetura.
